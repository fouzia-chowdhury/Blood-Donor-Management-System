# Blood Donor Management System

A web-based platform built with **Laravel** to connect blood donors and seekers. 

## 🚀 Key Features
* **Donor Availability Toggle**: Donors can switch their status (Available/Unavailable) from the dashboard.
* **Blood Group Filter**: Seekers can search for donors by specific blood groups.
* **Blood Request System**: Seekers can send requests directly to donors.
* **Notifications**: Donors receive notifications for any incoming requests.
* **Secure Authentication**: Built-in security for user registration, login, and profile management.

## 🛠️ Tech Stack
* **Framework**: Laravel 11
* **Frontend**: Tailwind CSS & Blade
* **Database**: MySQL
